# 🚀 每日免费节点自动抓取

> 手机访问不了节点网站？让 GitHub Actions 帮你每天自动抓取，生成一个固定网页随时查看。

## 📱 你只需要做一次

### 第 1 步：Fork 这个仓库

1. 注册/登录 GitHub（https://github.com）
2. 打开你 fork 后的仓库
3. 点 **Settings** → 左侧 **Actions** → **General**
4. 选 **Allow all actions and reusable workflows** → 保存
5. 点 **Settings** → 左侧 **Pages** → **Source** 选 `gh-pages` → 保存

### 第 2 步：手动触发一次

1. 点 **Actions** 标签页
2. 左侧选 **每日节点抓取**
3. 点 **Run workflow** → **Run workflow**

等 1-2 分钟，完成后你的页面地址是：
```
https://你的用户名.github.io/仓库名/
```

### 第 3 步：手机收藏这个链接

每天 UTC 00:00（北京时间 08:00）自动更新，打开就能复制订阅链接。

## 📋 手机导入方法

**Clash / Clash Verge Rev / FlClash：**
1. 打开客户端 → 配置 → 新建
2. 粘贴 Clash 链接 → 确定

**V2RayN / V2RayNG：**
1. 订阅 → 添加
2. 粘贴 V2Ray 链接 → 更新订阅

## ⚠️ 注意

- 免费节点多人共享，高峰时段可能较慢
- 仅用于技术研究，请遵守当地法规
- 每天自动更新，无需手动操作
